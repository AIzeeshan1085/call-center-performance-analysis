# 📊 Call Center Performance Analysis

## Excel Data Analytics & Interactive Dashboard

This project is an Excel-based Call Center Performance Analysis dashboard created to analyze call center operations, customer satisfaction, representative performance, call duration, and purchase activity.

The project demonstrates practical data cleaning, analysis, KPI development, Pivot Tables, Pivot Charts, and interactive Excel dashboard design.

## 🎯 Project Objective

The main objective of this project is to transform raw call center data into meaningful business insights using Microsoft Excel.

The analysis focuses on:

* Call volume
* Customer satisfaction
* Representative performance
* Call duration
* Purchase amount
* Monthly trends
* Day-of-week performance
* Customer activity
