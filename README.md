# 📊 Call Center Performance Analysis

### Excel Data Analytics & Interactive Dashboard

An Excel-based data analytics project focused on analyzing call center performance, customer satisfaction, representative activity, call duration, purchase performance, and operational trends.

---

## 📸 Dashboard Preview

![Call Center Performance Dashboard](Dashboard/call-center-dashboard.png)

---

## 🎯 Project Overview

This project transforms raw call center data into meaningful business insights using Microsoft Excel.

The dashboard provides a consolidated view of key performance indicators and helps identify patterns in call volume, customer satisfaction, representative workload, call duration, and purchase activity.

---

## 💡 Business Questions

This analysis was designed to answer questions such as:

* How many calls were handled?
* Which month had the highest call volume?
* Which days had the highest number of calls?
* Which representative handled the most calls?
* What is the average customer satisfaction rating?
* How many customers gave a 5-star rating?
* What is the total purchase amount?
* What patterns can be observed in call duration?

## 🔍 Key Insights

### 📞 Call Volume

A total of **1,000 calls** were analyzed.

**March** recorded the highest monthly call volume with **155 calls**, while **August** recorded the lowest with **50 calls**.

### 📅 Day-of-Week Analysis

**Saturday** recorded the highest number of calls with **161**, followed by **Wednesday** with **153 calls**.

### 👨‍💼 Representative Performance

**Representative R02** handled the highest number of calls, with **218 calls**.

### ⭐ Customer Satisfaction

The average customer satisfaction rating was **3.89 out of 5**.

**307 calls** received a 5-star rating, representing **30.7%** of all calls.

### ⏱️ Call Duration

The average recorded call duration was **89.85 units** based on the dataset.
