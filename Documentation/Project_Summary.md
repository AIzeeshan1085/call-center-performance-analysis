# Call Center Performance Analysis

## 1. Project Overview

This project is an Excel-based Call Center Performance Analysis and interactive dashboard created to transform raw call center data into meaningful business insights.

The analysis focuses on call volume, customer satisfaction, representative performance, call duration, purchase activity, and customer-level information.

The project demonstrates practical Microsoft Excel data analysis, KPI development, Pivot Tables, Pivot Charts, and dashboard design skills.

---

## 2. Project Objective

The primary objective of this project is to analyze call center performance and present important operational insights through an interactive Excel dashboard.

The analysis helps identify:

* Call volume trends
* Representative workload
* Customer satisfaction
* Purchase performance
* Call duration patterns
* Monthly call trends
* Day-of-week patterns
* Customer activity

---

## 7. Key Insights

### Call Volume

The dataset contains 1,000 total call records.

March recorded the highest monthly call volume with **155 calls**, while August recorded the lowest with **50 calls**.

### Day-of-Week Performance

Saturday recorded the highest number of calls with **161 calls**, followed by Wednesday with **153 calls**.

### Representative Performance

Representative **R02** handled the highest number of calls, with **218 calls**.

### Customer Satisfaction

The average customer satisfaction rating was approximately **3.89 out of 5**.

A total of **307 calls received a 5-star rating**, representing **30.7%** of all calls.

### Call Duration

The average recorded call duration was **89.85 units** based on the dataset.
